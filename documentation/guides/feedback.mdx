## Choose a type

| Type | Use it for | Color dot |
| --- | --- | --- |
| Feedback | General suggestions and observations | Green |
| Bug report | Something broken or behaving unexpectedly | Red |
| Feature request | A capability someone wants you to add | Purple |

The creation form places the type selector next to the board name. A post’s type also appears on its card and in its details. You can change a type where the selector or edit action is available to you.

## Update a status

| Status | Meaning |
| --- | --- |
| Open | Feedback has been received. |
| Planned | You intend to work on it. |
| In Progress | Work is underway. |
| Shipped | The change has been delivered. |

The public board’s completed filter may be labeled **Completed**, while the post status is **Shipped**. Status changes appear in the conversation history so visitors can follow progress.

## Add tags

In the main dashboard, open a post’s type/tag edit dialog. Select existing tags or create a new one, then save the post’s classification. Use tags for topics such as usability, mobile or onboarding. Tags are separate from the post’s type and status.

## Find popular feedback

Use **Trending**, **Top** or **Newest** to change the order. Trending highlights active conversations and engagement; Top emphasizes votes. A Trending badge is applied by Ent, rather than a tag you manually add.

Use the status filters to narrow the list. Search can find relevant feedback using titles, details, authors, types and tags.
