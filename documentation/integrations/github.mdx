---
title: GitHub
description: Create private changelog drafts from merged pull requests.
---

Connect a GitHub repository to create changelog drafts when pull requests are merged. GitHub automation is for **changelog drafts only**; it does not create or synchronize GitHub issues.

## Connect a repository

1. Open **Changelog** in the dashboard and select the GitHub icon.
2. Select **Connect GitHub**. On GitHub, install the Ent GitHub App and grant it access to the repository you want to use.
3. Authorize your GitHub account, return to Ent and choose that repository from the list.
4. Keep the dialog open while Ent imports previous merged pull requests. You can stop the import; reconnect the same repository to continue. Pull requests already imported are not duplicated.

A workspace owner or admin must connect the repository. Ent verifies that the authorizing GitHub user can access the installation and the selected repository. One GitHub installation can be connected to one Ent workspace at a time, and each workspace uses one repository.

## Review drafts

Ent creates a **private draft** for each eligible previous or newly merged pull request. The draft starts with the pull request's title and description; Ent does not rewrite it. Review the text and remove internal information before publishing. Existing drafts are never overwritten by a repeated import or webhook delivery.

A pull request labeled `skip-changelog`, `internal`, or `chore` is skipped. Labels such as `feature`, `bug`, `documentation`, and `performance` set the draft category; other pull requests use Improvement. Closed pull requests that were not merged are skipped.

To publish, open the draft in **Changelog**, edit or preview it, and select **Publish now** or schedule it. [Learn more about changelogs](/guides/changelog).

## Troubleshooting and disconnecting

If a repository is missing, make sure the GitHub App is installed on the right account and has access to it, and that your GitHub user can access it. Ent shows up to 1,000 repositories; if yours is missing, narrow the installation's repository selection on GitHub and reconnect.

An import can stop if authorization expires, the browser is closed, or GitHub is unavailable. Reconnect the same repository to retry; previously imported pull requests remain drafts and are skipped on retry. GitHub does not automatically redeliver failed webhook deliveries. A GitHub App owner can inspect and redeliver failures from the app's webhook delivery history.

Select the GitHub icon and choose **Disconnect** to stop creating drafts in this workspace. Existing drafts remain. Disconnecting in Ent does not uninstall the app; remove the installation in GitHub to revoke its access.
