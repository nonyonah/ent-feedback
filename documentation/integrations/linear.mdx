title: Linear
description: Connect feedback to Linear issues and sync their progress.

Connect Linear to create an issue from feedback or link an existing issue. Status changes sync both ways between a linked Linear issue and its Ent feedback request. Linear does not automatically create changelog drafts; use the [GitHub integration](/integrations/github) for those.

## Connect and configure

1. In **Settings → Integrations**, select **Connect Linear** and authorize access to your Linear workspace. An Ent workspace owner or admin can manage the connection.
2. Select a Linear team. The app can only show teams it can access in Linear.
3. Map the Ent statuses **Open**, **Planned**, **In progress**, and **Shipped** to four distinct states in that team, then save.
4. Open a feedback request and select **Send to Linear**. Create a new issue or enter an existing issue identifier from the configured team.

For status synchronization, enable Issue webhooks on the Ent OAuth app. Ent automatically sends status changes for linked requests to Linear and processes Linear issue updates through webhooks. You can also select **Sync to Linear** on a linked request to send its current Ent status again. The sync changes the issue status only; it does not overwrite its title, description, or comments. To create issues automatically for new requests, enable **Automatically create issues** in Linear settings and save. Existing requests can be sent with **Send to Linear**. Automatic delivery is retried by the maintenance scheduler when Linear is temporarily unavailable.

## Troubleshooting

If teams fail to load, use **Retry**. If no teams appear, check the app's team access in Linear and reconnect it from Ent. Confirm the Linear workspace has the required teams and workflow states. If the connection cannot be established, an Ent operator should verify the configured OAuth credentials and webhook secret.

Discord is currently paused and is not available to connect.
