---
title: "Troubleshooting"
description: "Recover from common setup and feedback issues."
---

## A workspace name or domain is unavailable

Choose a different value and wait for the availability check to finish. Domain identifiers need at least five characters. The display name and domain identifier are checked separately.

## I signed up but stayed on the public board

That is expected when registration starts from a public board. It lets you participate without setting up a product. Choose **My dashboard** to manage your own product; Ent will ask for workspace setup if you do not have one yet.

## A post or vote is missing

Check the current workspace, board, search and status filters. Make sure you are using the same signed-in account when comparing your personal active votes. Guest activity can use a separate browser identity.

## A change could not be saved

Read the message beside the form or in the toast. Keep your draft open and retry when the connection returns. A failed comment or feedback submission should keep its draft; do not submit several duplicate copies while one request is pending.

## I cannot create another board

Review the current board count and plan in **Settings → Billing**. Free allows two boards; Essentials allows five.

## An image will not upload

Check the file type and size guidance in the uploader. Try a smaller supported image and wait for the upload to finish before saving. Workspace/profile images and feedback attachments may have different limits.

For widget issues, use the [widget troubleshooting guide](/widget/troubleshooting). For unresolved problems, [contact support](/support).
