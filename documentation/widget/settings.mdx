---
title: "Widget settings"
description: "Choose what the widget asks visitors to share."
---

Open **Settings → Widget** in your workspace.

## Allow new feedback

The **Allow new feedback** switch controls submissions through the widget. You can prepare other settings while it is off.

## Ask for visitor details

Choose **Don’t ask**, **Optional** or **Required**, then choose whether to collect a name, email or both. These settings apply to anonymous submissions. Self-declared details are not a verified sign-in or host-app identity.

## Set a greeting

Write a short greeting for the form, or leave it empty to use the default. The greeting is part of the widget screen; it is not posted as a comment.

## Set a reply expectation

Choose Automatic, Within a day, A few days or Within a week. Automatic does not invent an estimate when there is no reply history. This setting communicates an expectation; it does not change staffing or routing.

## Save and preview

Choose **Save changes** to apply edits. **Discard** restores the saved values. Use **Preview widget** to inspect the result, then test it on the website where it is installed.
