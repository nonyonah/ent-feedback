---
title: "Widget settings"
description: "Choose what the widget asks visitors to share."
---

Open **Settings → Widget** in your workspace.

## Allow new feedback

The **Allow new feedback** switch controls submissions through the widget. You can prepare other settings while it is off.

## Ask for visitor details

Choose **Don’t ask**, **Optional** or **Required**, then choose whether to collect a name, email or both. These settings apply to anonymous feedback and live chat. Required details must be saved before the visitor can send a chat message. Self-declared details are not a verified sign-in or host-app identity. Email replies and feedback updates require a separate email confirmation. This confirms mailbox access, not the visitor’s name or identity; it does not sign them into Ent.

## Set a greeting

Write a short greeting for the feedback form and the start of a live chat, or leave it empty to use the default. The greeting is part of the widget screen; it is not posted as a comment.

## Set a reply expectation

Choose Automatic, Within a day, A few days or Within a week. Automatic does not invent an estimate when there is no reply history. This setting communicates an expectation; it does not change staffing or routing.

## Live chat

Enable chat and set your team’s availability and operators under **Settings → Chat**. When enabled, Live chat appears beside Feedback in the widget’s bottom navigation. Turning chat off removes that tab and returns an open widget to Feedback. Open widgets refresh configuration periodically; reopening also refreshes it. Chats restore after a refresh when browser storage is available. [Set up live chat](/guides/live-chat).

## Save and preview

Choose **Save changes** to apply edits. **Discard** restores the saved values. Use **Preview widget** to inspect the result, then test it on the website where it is installed.
